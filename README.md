# Hypnorai

Hypnorai is an experimental browser-based engine for creating mesmerizing procedural visuals.

## V1

The first prototype contains:

- Infinite Bounce template
- Real-time circular collision simulation
- Ball growth on collision
- Neon / Aurora / Sunset palettes
- Trail rendering
- Collision particles
- Glow rendering
- Speed and gravity controls
- Pause / play
- Deterministic variation seed

## Run

```bash
npm install
npm run dev
```
